**La Delicia – Restaurant Website**

A modern and elegant multi-page restaurant website built using HTML, CSS, and JavaScript.

The website includes:
- Home page
- Interactive food menu
- Shopping cart
- Table reservation
- About us
- Gallery
- Contact page
- Login and profile pages

**Technologies Used:**
- HTML5
- CSS3
- JavaScript

Designed with a modern layout, responsive design, and interactive features to provide a smooth user experience.
