# La Delicia Multi-Page Restaurant Website

## Pages
- `index.html` — first screen: Sign In / Create Account
- `home.html` — restaurant homepage
- `menu.html` — full menu, categories, search, favourites and add-to-cart
- `reservation.html` — table reservation request
- `about.html` — restaurant story
- `gallery.html` — food and restaurant gallery
- `contact.html` — contact details and message form
- `cart.html` — cart with quantity controls and total
- `profile.html` — demo profile

## Run
Open `index.html` in your browser. No React or build step is required.

## Notes
- Tailwind CDN is included, with additional custom CSS in `style.css`.
- Login/profile and cart use browser `localStorage` for demonstration.
- Reservation opens WhatsApp with the submitted details.
- Contact opens the visitor's email application.
- Replace the sample phone number, email, address and social links with the restaurant's real details.
- For production, connect authentication, reservations, contact messages and orders to a secure backend/database.
- Google Fonts, Tailwind CDN and Unsplash images require an internet connection.
